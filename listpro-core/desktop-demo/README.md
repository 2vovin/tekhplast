# ЛистПро — демоверсия Windows x64

[Скачать готовую демоверсию (ZIP)](https://github.com/2vovin/tekhplast/actions/runs/41811950655/artifacts/13313181158). Распакуйте и запустите `ListPro-Demo-0.1.0-win-x64.exe`. [Проверка запуска и SHA-256](RESULTS.md).

Отдельная сборка на актуальном вычислительном ядре и интерфейсе веб-версии. Основной сайт и прежняя полная программа сохранены.

- Программа начинает с пустого заказа. Новая строка содержит пустые размеры; нет встроенных заказов, готовых карт, частных контрольных наборов или автоматического восстановления прежнего ввода.
- Длина/ширина листа, материал и толщина редактируются в «Материал и настройки». Материал можно выбрать из подсказок или написать свой. Толщина является характеристикой заказа и не меняет двумерную геометрию.
- Первые две карты каждого нового расчёта показывают номера и размеры. Начиная с третьей — приблизительное слегка размытое превью без подписей, всплывающих размеров, номеров и списка назначенных деталей.
- Расчёт выполняется в отдельном Node-потоке. Перед передачей в интерфейс результат очищается: скрытые листы не содержат идентификаторов, точных координат/размеров, дерева и производственных операций. Встроенных раскладок нет ни в интерфейсе, ни в вычислительном пакете.
- Печать, PDF, SVG, CSV и экспорт результата недоступны. Заблокированы стандартные сочетания печати/сохранения, скачивания, внешние окна и DevTools. Сохранение проекта в этой пробной сборке также отключено; импорт своего списка и JSON доступен.
- На первых двух картах сохранены чекбоксы кромки и подчёркивания размеров. Кромка не вычитается из размера заготовки.

## Проверка материала и ограничения

Это геометрический полосный расчёт, а не подтверждение технологии конкретного оборудования. Выбор «Стекло» не создаёт последовательность надлома. Действующая пильная модель требует пропил не менее 0,1 мм; нулевой пропил не поддерживается. Прижимы, резка металла, пластика и стекла требуют отдельной технологической проверки. Цифровая подпись Windows пока отсутствует.

## Ограничение демоверсии — не защита исходного алгоритма

Локальная программа содержит вычислительный код. ASAR — упаковка, не шифрование. Демо ограничивает штатный интерфейс; не обещает защиты от модификации приложения, анализа кода, скриншотов или последовательного расчёта уменьшенных заказов. Для закрытого алгоритма нужен серверный расчёт. Первые два листа — на каждый расчёт, не пожизненная квота.

## Сборка и воспроизведение

В Windows после `npm install` в `../desktop`:

```
node scripts/prepare.cjs
node --test tests/*.test.cjs
node scripts/build.cjs
```

Существующий GitHub Actions `ListPro Desktop Windows` теперь собирает и запускает демоверсию на Windows. Артефакт `ListPro-Mebel-Windows-portable` содержит только демоверсию: `ListPro-Demo-0.1.0-win-x64.exe`. Изменения workflow не требуются; интеграция находится в `desktop/package.json`. Прежнюю полную версию можно отдельно собрать командой `npm run build:win:full` в `desktop`; в распространяемый демоартефакт она не включается.

При проверке создаётся искусственный заказ 900×700, 3 шт. на листе 1200×900, материал «Стекло», толщина 4 мм: он не встроен в пользовательский интерфейс. Проверяются пустой старт, пустые поля новой строки, изменённые параметры, три листа, скрытие третьего, блокировка печати и экспорта.
