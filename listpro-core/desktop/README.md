# ЛистПро Мебель — Windows Desktop, экспериментальная версия 0.1

Рабочая оболочка для математического ядра **Held-Strips PSS**, размещённого в соседней папке src/. Сайт «Техпласт» не используется и не меняется.

## Что работает

- Русский интерфейс, локально на компьютере Windows 10/11 (x64).
- Таблица деталей: №, Длина, Ширина, Количество, Текстура, Примечание.
- Параметры листа, ширина пропила и обрезка края.
- Редактирование проекта, сохранение и загрузка JSON; последний список деталей сохраняется локально.
- Загрузка готового проверенного контрольного примера 26 деталей.
- Кнопка «Раскроить» запускает настоящий held-strip-search.js в отдельном потоке worker_threads. Окно не блокируется.
- Карта раскроя с номерами/габаритами деталей, первичными полосами и контуром текущей заготовки.
- Переход по операциям CUT/ROTATE/FEED, красная линия пропила только внутри текущей заготовки, полный журнал операций.
- Экспорт SVG-карты и проверенного JSON результата.
- Независимая проверка через held-strip-validator.js перед показом результата.

## Важные ограничения

1. Сейчас подключён только PANEL_SAW_STAGED (Held-Strips). FORMAT_SAW, БАЗИС-экспорт, постпроцессоры и ЧПУ ещё не подключены.
2. Алгоритм исследовательский, не гарантирует оптимальность. Если поиск не нашёл карту, это не означает невозможность заказа.
3. Настоящие максимальные размеры подачи, ходы пилы, прижимы и минимальные удерживаемые остатки не заданы. Статус realMachineFeasibility = unknown. Карту нельзя отправлять напрямую на станок.
4. Автоматические первичные полосы выбираются из реальных размеров деталей; для некоторых заказов это ограничение может оказаться слишком строгим.
5. Текущая версия ищет только исходное направление H — альтернативная ось пока не допущена к производственной модели.
6. Даже успешный JSON нельзя считать сертификатом реальной программы ЧПУ. Не использовать без проверки технологом.

## Запуск проекта разработчиком

Требуется Node.js 20+ и Интернет для первого скачивания Electron.

Откройте терминал в папке listpro-core/desktop:

~~~powershell
npm install
npm start
~~~

Тесты:

~~~powershell
npm test
~~~

Создание переносимого Windows EXE:

~~~powershell
npm run build:win
~~~

Результат — файл dist/ListPro-Mebel-0.1.0-win-x64.exe, который включает Electron и не требует отдельно установленного Node.js.

Сборка Windows настроена в .github/workflows/listpro-desktop-windows.yml на Windows runner. Готовый Portable EXE должен появиться в разделе Artifacts после успешного завершения соответствующего GitHub Actions. Сам запуск workflow ещё не означает, что сборка прошла проверку.

## Данные и безопасность

Electron: nodeIntegration:false, contextIsolation:true, sandbox:true. Renderer не имеет прямого доступа к Node или файловой системе, только к ограниченному API preload.cjs. Ввод деталей валидируется отдельно. Внешние URL запрещены.

Демонстрационные файлы:
- ../benchmarks/bazis-26-corrected.json
- ../benchmarks/held-strips/result.json

Все изменения находятся в ветке listpro-core. Старое ядро не изменено.
