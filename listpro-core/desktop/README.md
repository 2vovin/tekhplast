# ЛистПро Мебель 0.2 — Windows x64

Локальная переносимая программа для Windows 10/11 x64. Node.js и интернет для расчёта не нужны. Для скачивания артефакта GitHub Actions требуется вход в GitHub.

## Запуск

1. Скачать ZIP **ListPro-Mebel-Windows-portable** из успешного Windows workflow.
2. Распаковать и запустить **ListPro-Mebel-0.2.0-win-x64.exe**.
3. Нажать **«Заказ 171 деталь»**: загрузятся исходные 98 строк и проверенный раскрой 11 листов / 349 резов.
4. **«Раскроить»** запускает новый поиск в отдельном потоке. Кнопка **«Остановить»** прекращает поиск; редактирование заказа во время расчёта заблокировано.
5. Собственный заказ можно ввести вручную, открыть из JSON или вставить из Excel кнопкой **«Вставить таблицу»**.

Приложение не подписано цифровым сертификатом. Статус соответствия конкретному станку остаётся неизвестным; программа не создаёт управляющие файлы ЧПУ.

## Возможности

- Алгоритм из расчёта заказа 171 деталь: adaptive-held-strip, оба первоначальных направления H/V, динамическое формирование полос, DP и перестройка групп листов.
- Удерживаемый остаток не поворачивается на любом уровне; независимый replay проверяет каждую принятую карту.
- Точные дробные размеры, в том числе 573,5 и 118,5 мм. При вставке допустимы точка и запятая.
- Колонки вставляемой таблицы: длина / ширина / количество. Разделители: табуляция, пробел, точка с запятой или вертикальная черта. Первую числовую строку импорт не отбрасывает.
- Флажок **«Текстура»** запрещает поворот детали. Кнопка **«Разрешить поворот всех»** снимает этот запрет для всего списка. Физические повороты отделённых заготовок проверяются отдельно.
- Карты всех листов, первичные полосы, номера экземпляров, размеры, журнал CUT/ROTATE/FEED и переход к соответствующему листу при просмотре операций.
- Сохранение/открытие проекта JSON, экспорт карты SVG и результата JSON.
- Проверенные примеры на 26 и 171 деталь. Точное совпадение заказа допускает старт с повторно проверенного известного решения; новый поиск всё равно выполняется. При изменении размеров, количества, текстуры, листа, пропила или обрезки чужое решение не используется.
- Расчёт не обращается к внешним сервисам. Веб-сайт «Техпласт» не изменён.

## Ограничения

По умолчанию выполняется до 100 вариантов для каждого первого направления и до 100 для каждой выбранной группы листов. Это ограниченный поиск, оптимальность не доказана. Пример 171 детали сохраняет минимум известное проверенное решение на 11 листах; отсутствие 10-листового результата не означает невозможность.

Предельные размеры прижимов, удержания, подачи и хода пилы не заданы. Отметка «проверено» относится к геометрии и согласованной абстрактной PSS-модели. Пакет не является сертифицированным постпроцессором станка.

Проекты сохраняются в выбранный пользователем JSON; последний список также восстанавливается из локального хранилища приложения. Рекомендуется явно сохранять рабочие проекты.

## Разработка и проверка

~~~powershell
cd listpro-core/desktop
npm install
npm test
npm start
npm run build:win
~~~

Команда build:win создаёт настоящий переносимый EXE, затем **запускает этот EXE** и автоматически проверяет:
- загрузку встроенных ресурсов 26/171;
- повторный расчёт 171 детали через интерфейс и рабочий поток;
- переключение листов и журнала операций;
- вставку дробных размеров;
- остановку расчёта.

При ошибке сборка CI завершается неуспешно, EXE не загружается как успешный артефакт. В журнале сохраняются WINDOWS_SMOKE_REPORT и WINDOWS_BUILD_SHA256. Артефакт workflow хранится 14 дней; исходный код позволяет повторить сборку.

Безопасность Electron: contextIsolation, sandbox, nodeIntegration:false; IPC предоставляет только конкретные операции; внешняя навигация запрещена. Отладочный запуск --smoke-report применяется только в автоматической проверке и использует отдельное временное локальное хранилище.
