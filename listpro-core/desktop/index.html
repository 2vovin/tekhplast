ЛистПро Мебель · первая версия

Приложение использует экспериментальный алгоритм Held-Strips и независимую проверку физической последовательности резов. Раскрой выполняется локально на компьютере.

Тип станка сейчас один: пильный центр PSS. Требования по ходу пилы, прижимам, безопасному удержанию и подаче неизвестны — результат не является программой ЧПУ и не подтверждён для конкретного оборудования.

Сохранение проекта: JSON. Экспорт карты: SVG. Результат: проверенный JSON с операциями. Для промышленного использования необходима проверка технологом.
