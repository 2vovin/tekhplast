# База проверенного опыта, версия 1

Реализовано локальное накопление: деревья удачных полос, сочетания нескольких листов («дебюты»), статистика повторений и ранее успешный широкий перебор кандидатов. Это case-based learning / накопление опыта поиска, а не обучение весов нейросети.

## Что действительно сохраняется

- Анонимизированные деревья резов с размерами исходных деталей и разрешённой ориентацией; идентификаторы, экземпляры, названия проектов, координаты и полный журнал резов не сохраняются.
- До 128 структур отдельных листов и до 16 сочетаний взаимодополняющих листов. Книга целого сочетания предотвращает жадное повторение одной полосы, которое лишает другую необходимых деталей.
- До 64 рекомендаций широкого перебора для похожих по характеристикам заказов, частоты использования и число завершённых обучающих расчётов. Рекомендация записывается, если этот ход дал нижнюю границу числа листов.

Хранилище: `experience-v1.json` в локальном каталоге данных Windows-приложения. Поставляемая программа не содержит этой базы, старых заказов или встроенных решений. Начальная форма всегда пуста. Обновления файла атомарные; запись использует блокировку и свежую версию базы. При ошибке доступа расчёт возвращается, а интерфейс сообщает, что изменения базы не сохранены. База ограничена по размеру; это не бесконечное сохранение всех расчётов.

## Использование на новых заказах

Сначала пробуются сохранённые сочетания; затем отдельные структуры. Идентификаторы и количества назначаются заново. Для похожих размеров разрешено пробное сопоставление: сумма относительных отклонений двух размеров до 8%. Это только эвристика допуска к проверке; реальные размеры никогда не округляются и не подменяются. Деревья пересчитываются с текущим пропилом, листом и обрезкой и проходят независимый replay. Текстура проверяется по новому заказу.

Если найден проверенный результат на нижней границе по площади, обычный повторный расчёт может закончиться сразу. Минимальность числа резов не заявляется. Если опыт не подходит или остаётся лишний лист, запускается свежий поиск и сохраняется лучший результат по выбранному критерию. Обучающий скрипт `forceSearch` продолжает поиск даже при найденной нижней границе, меняя seed по раундам для поиска новых приёмов.

## Скрипты

```
node scripts/train-experience.js /путь/experience-v1.json /путь/order.json --rounds 3
```

Новые заказы рассчитываются; победившие варианты заново компилируются/валидируются перед записью. Возможен приём уже проверенного JSON результата пользователя:

```
node scripts/train-experience.js /путь/experience-v1.json /путь/result.json --verified-results
```

Даже в этом режиме выполняется новый независимый replay: отметка «проверен» внутри файла не считается доказательством. Для чтения Windows-программой укажите её файл базы. Во время обучения не запускайте второй обучающий процесс на том же файле: занятая база отклоняет запись вместо перезаписи конкурентных изменений.

## Самостоятельная тренировка

```
node scripts/self-train-experience.js /путь/experience-v1.json --orders 20 --seed 42
```

Генерируются новые случайные задания без заказов клиентов. Число задач ограничено 1–100; поиск меняет seed, свежие варианты сравниваются с опытом, каждый принятый ход проходит replay. На двух сгенерированных задачах seed=42 база выросла с нуля до 7 структур / 2 книг / 2 расчётов. Это проверка процесса накопления, а не доказательство оптимальности полученных тренировочных раскроев.

## Фактическое испытание

Скрипт принял ранее сохранённые результаты 128 и 171 детали после нового replay; создана отдельная экспериментальная база из 18 структур / 2 книг / 2 расчётов. Эта база **не включена в EXE** и не добавлена как встроенный пример.

| Заказ | Свежий поиск ранее | Повтор с базой опыта | Результат |
|---|---:|---:|---|
| 128 деталей | 52 582 мс | 20 мс | 8 листов / 230 резов / 63 поворота |
| 171 деталь | 106 916 мс | 16 мс | 10 листов / 338 резов / 114 поворотов |

Это ускорение **повторного использования уже изученных решений**, а не ускорение поиска с нуля и не доказательство такого выигрыша на неизвестных заказах. Измерения зависят от машины. Машиночитаемые результаты: `replay.json`.

Независимые тесты также проверили изменённые размеры 401×301 вместо 400×300, перенос приёма широкого поиска без готовых деревьев, невозможную текстуру/габариты, дедупликацию, перестановку идентификаторов остатка, сохранность базы при ошибке и замену неудачного опыта лучшим свежим решением. Chromium с настоящим worker подтвердил запись опыта и повторное использование при втором расчёте; пустой старт, скрытие карт после второй и блокировка печати/экспорта сохранены.

Ограничения: это первая библиотека приёмов, не универсальный самообучающийся оптимизатор. Извлечение произвольных вложенных мотивов и самогенерация нового кода отсутствуют. Совместимость с реальным оборудованием не подтверждается базой опыта. Изменение технологической модели требует нового профиля/версии базы; неизвестные версии не исполняются.
