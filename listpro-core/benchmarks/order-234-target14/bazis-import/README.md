# Данные для загрузки заказа в БАЗИС-Раскрой

Это файлы списка деталей: **75 строк / 234 экземпляра**, площадь 65,644689 м².
Размеры 779,5 и 537,5 сохранены как числовые значения, без округления.

- listpro-234-bazis.xls — настоящий Excel 97–2003 / BIFF8.
- listpro-234-bazis.xlsx — современная книга Excel как дополнительный вариант.
- parts-ru.txt — три колонки с табуляцией, десятичная запятая, без заголовка.
- generate.cjs — повторное формирование из ../input.json; для него отдельно нужен модуль xlsx.
- validation.json — результаты обратного чтения файлов.

В доступном руководстве периода установленного пользователем БАЗИС 10
описан импорт **списков** из XLS/TXT/OBL
(см. ../../../docs/BAZIS-10-MANUAL-ANALYSIS.md).
Поэтому основной вариант — XLS. Импорт в реальную установленную программу
пока не выполнен: доступа к ней нет. Поддержка XLSX в конкретной версии
не заявляется как проверенная.

## Содержимое книги

На листе **«Детали»** только числовые данные, без строки заголовка:
**A — длина, B — ширина, C — количество**.
Диапазон A1:C75. Порядок соответствует номерам исходных 75 строк.
Дубли строк сохранены отдельно.

Лист «Параметры» справочный. Он не настраивает БАЗИС автоматически.
Лист «Контроль» содержит исходные номера и разрешение поворота.

## После загрузки списка

Сопоставьте A/B/C с длиной/шириной/количеством средствами импорта вашей версии.
Выберите фактический материал и установите лист 2750×1830 мм,
пропил 5 мм, обрезку 10 мм с каждой стороны и разрешение поворота всех деталей.
Параметры технологического оборудования применяйте по реальному профилю станка.
Если программа предлагает объединение одинаковых строк, учитывайте, что
номера позиций после объединения могут отличаться от наших карт.

Контроль перед расчётом: 234 экземпляра, площадь 65,644689 м²;
819×779,5 — 1 шт., 1003×537,5 — 1 шт., 779,5×168 — 1 шт.,
1800×297 — **4 шт.**

## Перенос именно готовых 14 карт

Наш полный план находится в ../result.json, PDF — в ../maps.pdf.
**XLS/TXT передают детали; готовые карты и дерево резов ими не перенесены.**
БАЗИС при самостоятельном расчёте может построить другую раскладку.

Готовый проект в родном формате БАЗИС здесь не создан.
Для его подготовки нужно установить поддерживаемый способ обмена
конкретной версии. Нужен небольшой пример сохранённого проекта/результата
из этой версии и проверка его открытия в самой программе.
Форматы и команды более новой версии 2026 года не считаются подтверждёнными
для БАЗИС 10. Импорт JSON ListPro в БАЗИС не заявляется.

## Проверка файлов

Книги сформированы SheetJS 0.18.5 (официальная сборка тега v0.18.5,
blob 16e013fceefc689cabc5be352099199847a0e67f).
Каждая книга заново прочитана: все три числовых столбца построчно
равны исходному заказу. TXT также разобран и сверен построчно.
Это проверка файлов обмена, а не подтверждение импорта или раскроя в БАЗИС.
