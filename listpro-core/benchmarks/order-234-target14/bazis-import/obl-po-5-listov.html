Задания OBL по пяти листам

Создаются три задания из сохранённой раскладки на 14 листах: листы 1–5, 6–10 и 11–14. БАЗИС заново рассчитывает каждую группу. При расчёте число листов может отличаться.

По умолчанию загружается проверенная раскладка на 14 плит. Содержимое OBL обрабатывается на вашем компьютере.

Раскладка из файла

Для работы без интернета заранее сохраните раскладку на 14 плит (result.json). Можно выбрать и другой файл раскладки ЛистПро.
