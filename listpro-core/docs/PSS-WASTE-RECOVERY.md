# PSS 1.3 — обязательное использование свободных участков до открытия нового листа

## Дефект, обнаруженный пользователем на контрольном заказе

В `benchmarks/manual-26-pss-1.3.json` все пять деталей №9 размером **238×180 мм** отправлены на **второй лист**, несмотря на то, что на первом листе уже имеется **отдельный прямоугольный лист дерева гильотинного раскроя типа waste**:

- лист 1; координаты исходного материала `x=2420, y=1422`;
- габариты **320×398 мм**, площадь 127360 мм²;
- область расположена справа от готовой детали №7 размером 297×297 мм, внутри существующей первичной полосы с настоящим якорем №4 и шириной полосы 398 мм;
- запрет поворота самих деталей действует: для №9 сохранять исходную ориентацию **238 по X и 180 по Y**.

В существующий участок **геометрически помещаются ДВЕ детали №9** при пропиле 5 мм:

- №9 (экз. 1): `x=2420, y=1422, w=238, h=180`;
- №9 (экз. 2): `x=2420, y=1607, w=238, h=180`;
- между ними керф 5 мм; по ширине остаётся 320 − 238 − 5 = **77 мм**, по высоте 398 − (180 + 5 + 180) = **33 мм**.
- Размещение допустимо **геометрически** внутри указанного реального waste-листа. Производственная выполнимость PSS **не доказана этим расчётом**, её следует подтвердить созданием нового сквозного дерева разбиений, повторной генерацией операций и независимым replay-валидатором со всеми ролями/поворотами/текстурой.

Две детали №9 **могли бы** быть сняты со второго листа, но это пока не означает, что все пять попадут на первый: остальные три остаются отдельной задачей поиска.

## Новое требование к оптимизатору

**Прежде чем оставлять детали на дополнительном листе, алгоритм обязан выполнять повторное заполнение всех доступных прямоугольных отходов (waste leaves) на уже использованных листах**, если допустимый локальный раскрой можно построить без нарушения существующих операций/полос/якорей. Экономия листов — первый приоритет; использование свободного места на предыдущем листе повышает пригодный остаток последующего листа и не должно пропускаться из-за локальной оценочной функции крупных отходов.

### Инженерный механизм

1. Получить список **настоящих waste-листьев в дереве**, а не только визуально пустых зон, которые трудно отделить.
2. Сформировать пул экземпляров, находящихся на более поздних листах; проверять их размеры, ориентацию относительно текстуры, керф и способность физически получить их из данного отхода.
3. Для каждого подходящего waste-листа применить bounded 2D guillotine subsolver / DP. Он должен заменить `waste` на `CUT`-поддерево с настоящими деталями и остатками, **не переименовывая существующие первичные полосы и не подменяя якорь**.
4. Повторно создать весь PSS-операционный план, включая фактические операции подачи и физические повороты каждого `blankId`.
5. Прогнать старый **независимый** `pss-validator` / `physical-replay` (при необходимости дополнять валидатор отрицательными тестами, но не отключать ограничения).
6. Только подтверждённый результат принимать. Затем удалить переселённые экземпляры со следующего листа, вновь уплотнить оставшиеся и переоценить все листы, полезные остатки, резы и операции.
7. Стремиться к полному удалению дополнительного листа; если невозможно, честно показать, сколько деталей перенесено, насколько увеличился цельный остаток и почему остальные не перенесены.

## Обязательные тесты

- **Регрессия `manual-26-pss-1.3`:** найти waste-лист `(2420,1422,320,398)`, обнаружить два реальных экземпляра №9 `238×180`, построить локальное гильотинное дерево из двух деталей + отходов и отдельно проверить новое физическое PSS-прохождение. Нельзя объявлять PSS valid только по размерам.
- **Некорректный керф:** при недостаточных габаритах после добавления пропила отклонить.
- **Запрещённый поворот детали:** отклонить 180×238 как «развёрнутую деталь» при направленной текстуре; физический поворот самой отделённой заготовки остаётся отдельным понятием.
- **Некорректная стадия:** отвергать перепланировку waste-листа, если она потребовала недопустимого поворота `PRIMARY_REMAINDER` или перепутала порядок первичных резов.
- **Наличие реального якоря:** не создавать новую полосу только ради заполнения отхода. Использовать уже физически отделённую полосу и её waste-лист.
- **Регрессия производственного профиля:** та же геометрическая область может быть пригодной в FORMAT_SAW, но недопустимой в PSS; статусы следует разделять.

## Цели сравнения

Для текущего заказа исходный PSS 1.3: 26/26, 2 листа, 50 резов, 40439 мм, 16 поворотов, 118 операций. Результат перемещения двух №9 считать новой проверенной гипотезой **только после независимой валидации**; никаких гарантированных итоговых чисел не назначать заранее.

Документ не утверждает, что однолистовой PSS-раскрой возможен. Не менять исходные размеры и не вводить неподтверждённые возможности станка.
