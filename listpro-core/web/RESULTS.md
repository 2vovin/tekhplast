# ЛистПро Web 0.1 — полноширинная карта

Дата: 2026-11-03. База ядра: `1680d53bd9210ec9d7c882e450300caa22392907`.

## Выполнено

- Реализован автономный русскоязычный сайт по предоставленному образцу: светлый фон, зелёные действия, цветные детали; карта расположена по центру на всю ширину рабочей области.
- Боковые панели заменены вкладками. На узком экране панели переходят в вертикальную компоновку, карта сохраняет пропорции, доступны масштабирование и полноэкранный режим.
- Расчёт в Web Worker использует неизменённые модули ядра; новая обёртка задаёт входные ограничения и целевую функцию.
- Загрузка CSV/TSV/TXT и JSON, вставка из Excel, редактирование, разрешения поворота деталей.
- Карта всех листов, последовательность операций, локальная геометрия текущей физической заготовки и дочерних частей.
- Экспорт SVG/JSON/CSV, сохранение проекта, печать всех карт.
- Раздел тарифов обозначает планируемую платную версию. Приём платежей не реализован.

## Проверки

Добавлены отдельные тесты:
- побайтовая воспроизводимость HTML из исходников;
- повторная независимая проверка всех примеров;
- два варианта настоящего расчёта 44 деталей;
- изменённый заказ с дробями, сохранение количества и текстуры;
- повреждённая карта, недопустимый ввод и раннее ограничение количества;
- выполнение встроенного Worker через Node worker_threads;
- защита границ script при встраивании данных;
- DOM-контракты загрузки, вкладок, навигации, изменения цели, расчёта, экспорта, импорта и отмены.

DOM-контракты используют минимальный тестовый DOM. Они не заменяют запуск настоящего браузера и проверку внешнего вида. Скриншоты Chrome/Edge и ручная визуальная приёмка не выполнены: рабочая среда не запустилась.

GitHub Actions: ожидается запуск после сохранения коммита; фактический итог будет добавлен после проверки.

## Ограничения и публикация

Публикация в Sites заблокирована ошибкой запуска управляемой среды, а не запросом дополнительного разрешения. Поэтому публичный URL не заявляется. `web/index.html` — готовый автономный файл; его можно скачать из GitHub и открыть локально или разместить на статическом хостинге.

Универсальная оптимальность не заявляется. Верифицирована конкретная абстрактная held-strip модель, не реальный станок. Авторизация, облачное хранение, платежи, общий склад остатков, прямой XLSX-импорт, DXF и ЧПУ-экспорт отсутствуют. Вставка из Excel поддерживается через три колонки/CSV.

Предыдущие алгоритмы, эталоны, ветка main и сайт «Техпласт» не изменены.
