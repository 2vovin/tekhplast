# ЛистПро Web 0.1 — полноширинная карта

Дата: 2026-11-03. База ядра: `1680d53bd9210ec9d7c882e450300caa22392907`.

## Выполнено

- Реализован автономный русскоязычный сайт по предоставленному образцу: светлый фон, зелёные действия, цветные детали; карта расположена по центру на всю ширину рабочей области.
- Боковые панели заменены вкладками. На узком экране панели переходят в вертикальную компоновку, карта сохраняет пропорции, доступны масштабирование и полноэкранный режим.
- Расчёт в Web Worker использует неизменённые модули ядра; новая обёртка задаёт входные ограничения и целевую функцию.
- Загрузка CSV/TSV/TXT и JSON, вставка из Excel, редактирование, разрешения поворота деталей.
- Карта всех листов, последовательность операций, локальная геометрия текущей физической заготовки и дочерних частей.
- Экспорт SVG/JSON/CSV, сохранение проекта, печать всех карт.
- Раздел тарифов обозначает планируемую платную версию. Приём платежей не реализован.

Печать через кнопку и стандартную команду браузера формирует карту и её список рядом на A4 в альбомной ориентации. В шапке — материал, размер листа и количество деталей; внизу — параметры пропила/обрезки. Длинный список разбивается по 30 позиций: карта повторяется на странице продолжения, строки не теряются и не обрезаются. Сбор данных списка общий для всех режимов.

## Web 0.7 — компактный список и кромка (2026-11-04)

В режиме одного листа ширина списка уменьшена с 280 до 210 px, уменьшены отступы и высота строк. Вся пара «карта + список» центрируется с промежутком 12 px; карта сохраняет ограничение 80vh. На контрольном листе 10 мебельного заказа: 21 позиция занимает 721,25 px по высоте рядом с картой 1116×764,77 px (окно 1440×1080). На узких экранах список остаётся справа.

В таблице деталей добавлены четыре настройки кромки: верх, право, низ, лево относительно исходной детали, длина которой направлена горизонтально. Значения: нет / 0,4 / 0,8 / 1 / 2 мм. Настройка применяется ко всем экземплярам позиции и сразу обновляет карту без нового поиска. Кромка обозначена точками вдоль соответствующих сторон, немного внутрь контура; видна в режиме одного листа, сетке, физическом просмотре, SVG и печати. Для повёрнутой детали применяется соглашение 90° по часовой стрелке; физические повороты заготовки дополнительно поворачивают отметки. Настройки сохраняются в JSON проекта/результата и CSV. В списке и печати указаны выбранные стороны и толщина.

Это обозначение кромления заготовок: размеры раскроя сохраняются, вычет толщины кромки из готового размера не реализован. Такое поведение явно подписано в форме и печати. Оптимизатор, геометрические размеры и технология резов не менялись.

## Web 0.8 — мебельное обозначение кромки и быстрый выбор (2026-11-04)

По уточнению пользователя пунктир на карте сохранён. Подчёркивания добавлены к размерам в списке деталей, в полях редактирования длины/ширины, в кнопках выбора кромки, списках рядом с картами и при печати. Одна черта означает одну окромлённую сторону соответствующей длины, двойное подчёркивание — обе. Число черт не зависит от толщины. Для исходного размера длины учитываются верх/низ, для ширины — лево/право.

Вместо четырёх постоянно открытых списков доступны две кнопки «По длине» и «По ширине»: 0 → 1 → 2 → 0 сторон. Общая толщина выбирается рядом. При первом включении без предыдущих настроек используется 2 мм, значение видно в форме. Конкретные стороны и неодинаковая толщина остаются в раскрываемом разделе «По сторонам»; при добавлении второй стороны уже заданная сторона сохраняется. При одном окромлённом торце быстрый выбор начинает с верха для длины и слева для ширины. Размеры заготовок не меняются.

Проверены цикл кнопок, независимость двух направлений, подчёркивания в полях/списках/PDF, сохранение точек на карте, изменение толщины без изменения числа черт, точная настройка сторон, изменение размера и обязательный пересчёт, прежние повороты и JSON round trip.
