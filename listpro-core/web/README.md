# ЛистПро — веб-версия

Рабочий сайт в стиле предоставленного примера: карта по центру на всю ширину, без боковой колонки. Детали, настройки, остатки и операции открываются отдельными вкладками.

## Открыть

Скачайте **index.html** целиком и откройте в современном Chrome, Edge или Firefox. Файл автономный: внешний сервер, Node.js и установка зависимостей для использования не нужны. Для размещения на обычном статическом хостинге достаточно того же файла. Нужна поддержка JavaScript, SVG и Blob Web Workers; политика хостинга должна разрешать встроенные скрипты и worker-src blob:.

В GitHub используйте Download raw file. Обычная страница просмотра HTML в GitHub не запускает сайт.

## Возможности

- Настоящий расчёт исходным held-strip ядром в отдельном Web Worker.
- Загрузка CSV/TSV/TXT, вставка трёх колонок из Excel, JSON проектов; десятичная запятая.
- Изменение деталей, количества, поворотов, размеров листа, пропила и обрезки.
- Приоритет: крупные цельные остатки или меньше резов/поворотов, после числа листов.
- Масштабирование, полноэкранная карта, все листы заказа.
- Пошаговые CUT / ROTATE / подачи; текущая физическая заготовка и удерживаемые дочерние части.
- Сохранение проекта, SVG текущего листа, JSON результата, CSV деталей и операций; печать всех листов / PDF через браузер.
- Три независимо проверяемых примера: 26, 44 и 171 деталь.
- Данные обрабатываются в браузере, автоматически никуда не отправляются. Для сохранения между сеансами скачайте проект.

## Сборка и проверка

Из listpro-core:

    node web/build.cjs
    node --test tests/web.test.js
    npm test
    npm run benchmark

Сборка создаёт web/index.html и web/dist/index.html. Сборщик включает исходники src напрямую, без перевода алгоритма на другой язык и без ручного упрощения формул. Тест проверяет побайтовое совпадение сохранённого HTML со сборкой из текущих исходников.

engine.cjs — обёртка ввода, выбора приоритета и поиска. app.js — интерфейс. bundle.cjs — небольшой статический CommonJS-сборщик; build.cjs — Node CLI. examples.json содержит входные данные и деревья исторических решений, но не заранее доверенные статусы: при открытии они проходят новый replay.

## Ограничения

Это экспериментальная локальная веб-версия, не коммерческий SaaS. Авторизация, синхронизация, оплата и склад остатков между заказами не подключены. Тарифный раздел явно отмечает будущие возможности.

Параметры реального станка неизвестны. Проверяется конкретная абстрактная held-strip модель: удерживаемый остаток не поворачивается на любом уровне; исходный лист не вращается; реально отделённая полоса допускает один поворот. Полный технологический план экспортируется в JSON, программа ЧПУ не формируется.

Поиск ограничен бюджетом, оптимальность для произвольного заказа не доказана. Для одного типа деталей сначала применяется существующий перебор двухлистовых полосных паттернов; если решения в этом семействе нет, используется адаптивный поиск. Для общего случая: H/V, 100 итераций каждого направления, перераспределение групп листов, seed 42. Примеры с совпадающими параметрами используются как проверенный начальный кандидат. На больших заказах расчёт можно остановить.

Технические границы веб-ввода: 500 строк / 2500 экземпляров, стороны листа до 20000 мм, пропил 0.1–30 мм, обрезка 0–200 мм (ненулевая не меньше пропила). Это ограничения данной версии интерфейса, не паспортные характеристики станка.

Сайт опубликован в Sites: https://listpro-cutting.vlonir.chatgpt.site — доступ владельцу. Автономный HTML также остаётся доступен для локального запуска. Размещение не включает оплату или собственную систему авторизации.

Проверен Chromium 154, настольный экран 1440×1080 и мобильный 390×844. Скриншоты: qa/desktop.png и qa/mobile.png. Для повторения браузерного сценария установите Playwright и его Chromium в отдельной среде, запустите HTTP-сервер для web/ на порту 4173 и выполните node web/qa/browser-check.cjs. Переменные PLAYWRIGHT_MODULE, CHROMIUM_PATH, LISTPRO_BASE_URL и LISTPRO_QA_OUTPUT позволяют задать установленные зависимости, адрес и каталог результатов. Пример в данной среде:

    PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright CHROMIUM_PATH=/usr/bin/chromium node web/qa/browser-check.cjs

Исходники проекта и тесты хранятся в ветке listpro-core. Sites получает автономный HTML и манифест в собственный репозиторий публикации; это отдельный SHA, не ветка main репозитория Техпласт.
